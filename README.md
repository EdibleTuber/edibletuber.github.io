# edibletuber.github.io

Personal write-ups. Jekyll on GitHub Pages, styled with Tufte CSS (MIT).

## Publishing a post

1. Write `_posts/YYYY-MM-DD-title.md` with front matter (`layout: post`, `title`, `date`).
2. Commit and push to `main`. Pages builds the site in a minute or two.

Unfinished posts go in `_drafts/`. Pages does not build that folder, but the repo is public, so anything pushed there is readable. Keep sensitive drafts out of this repo until they are sanitized.

## Sidenotes

Inline in the text: `<span class="sidenote">Note text.</span>`

## Settings

Settings, Pages: deploy from branch `main`, folder `/ (root)`.
